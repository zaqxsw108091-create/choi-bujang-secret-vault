점령된 자료실

자료는 코드 밖 학습용 DB에 있고, 서버(/api/notes)가 로그인 확인을 마친 요청에만 보여 줍니다. 로그인하면 내 가상 메모를 추가·수정·삭제할 수 있습니다.

이전에 공개된 커밋과 배포 기록은 지워지지 않았습니다. 그때 공개된 자료의 노출은 해소되지 않았습니다.
오프라인입니다. 이 앱은 메모를 기기에 저장해 두지 않으므로 인터넷이 다시 연결되기 전에는 메모를 볼 수 없습니다. 연결되면 자동으로 다시 불러옵니다.
실행 방식
확인 중
기기 승인
서버 확인 전

설치했다는 표시만으로 기기가 믿을 수 있는 것은 아닙니다. 기기 승인은 서버가 정하며, 이 화면은 서버가 마지막 보호 요청에 준 응답만 그대로 보여 줍니다.

로그인되어 있습니다.

이 기기는 서버가 등록 기기로 확인하기 전까지 자료실을 열 수 없습니다. 승인 요청 버튼은 요청만 보냅니다. 승인은 이 화면이 아니라 서버에서 자료실 주인이 확인 코드를 대조한 뒤에만 됩니다. 기기 키와 로그인 기록은 이 화면의 메모리에만 있어서, 화면을 닫거나 새로고침하면 사라지고 다시 로그인하고 승인받아야 합니다.

아직 승인을 요청하지 않았습니다.

탈환 작전실 요약 — 서버가 이번 요청에서 실제로 읽은 숫자만 "확인됨"으로 적습니다. 운영 엔진과 이어지지 않은 항목은 "미실행"이며, 메모 제목·본문은 싣지 않습니다.

  • 로그인하면 내 가상 메모가 보입니다.
