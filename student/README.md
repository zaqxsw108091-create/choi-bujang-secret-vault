# 내 PC 관제 대시보드 (마지막 총공세)

내 Windows PC의 상태를 **읽어서 한 화면에 보여 주는** 작은 앱입니다. 보안 제품이 아니라, 상태를 눈으로 확인하는 점검 화면입니다.

## 실행 방법 (포장 없이, 프로젝트 폴더에서)

필요한 것: **Node.js 22 이상 권장** (https://nodejs.org). 따로 `npm install`은 필요 없고, 관리자 권한도 필요 없습니다.
(18.15 이상이면 켜지도록 만들었지만 시험은 Node 22에서만 했습니다.)

| 하고 싶은 것 | 명령 |
| --- | --- |
| 실제 내 PC 상태 | `node student/server.mjs` 또는 `student\start.bat` 더블클릭 |
| 예제 화면 | `node student/server.mjs --demo` 또는 `student\start-demo.bat` |
| 공용 PC(학원 등): 기록을 파일에 안 남김 | `student\start-shared.bat` 또는 `node student/server.mjs --no-save` |
| PowerShell로 켜기 | `.\student\start.ps1` / 예제는 `.\student\start.ps1 -Demo` |
| 포트 바꾸기 | `node student/server.mjs --port=4200` |

`.bat`은 브라우저를 자동으로 엽니다. 직접 `node`로 켰다면 터미널에 나온 주소(보통 **http://127.0.0.1:4173**)를 엽니다.
4173번을 이미 쓰고 있으면 4174, 4175…로 빈 번호를 찾아 켜고, 터미널에 실제 주소를 보여 줍니다. 끄려면 터미널에서 `Ctrl+C` (또는 창 닫기).
`.ps1`이 "스크립트 실행 불가"로 막히면 `node` 명령이나 `.bat`을 쓰세요. 정책은 바꾸지 않아도 됩니다.
예제 화면은 위쪽에 **"예제 (실제 PC 값이 아니에요)"** 표시가 나옵니다.

## Node.js가 없는 PC (학원 컴퓨터 등, 설치 없이)

Node가 없고 설치 권한도 없다면 압축만 풀어서 쓸 수 있습니다. 이 앱이 하는 일이 아니라 사용자가 직접 하는 준비입니다.

1. https://nodejs.org/en/download 에서 **Windows Binary (.zip)** 을 받습니다.
2. 압축을 풀고, 안에 있는 파일들을 `student\node` 폴더에 옮깁니다. (`student\node\node.exe`가 있어야 합니다.)
3. `student\start.bat`을 더블클릭합니다. `start.bat`이 `student\node\node.exe`를 먼저 찾아 씁니다.

`student\node` 폴더는 Git에 올라가지 않습니다. PC에 설치하거나 설정을 바꾸는 것은 없습니다.

## 여러 Windows PC에서 쓸 때 (대비한 것)

- **PowerShell이 막힌 PC**: 명령을 인코딩해서 `-NoProfile`로 실행하고 실행 정책 설정은 바꾸지 않습니다. 실행이 안 되면 그 항목만 이유와 함께 "확인 불가"가 됩니다.
- **방화벽 조회 명령이 막힌 PC**: 레지스트리의 방화벽 설정값을 읽기만 하는 방법으로 한 번 더 시도합니다. (내 PC 설정값이며, 그룹 정책이 따로 있으면 실제와 다를 수 있습니다.)
- **폴더에 쓸 수 없는 PC**: 임시 폴더에 기록하고, 그것도 안 되면 메모리에만 기록합니다. 화면 위에 저장 방식이 표시됩니다.
- **공용 PC**: `--no-save`는 기록을 파일에 남기지 않습니다. 개인 정보(PC 이름·사용자 이름 등)는 어느 모드에서도 저장하지 않습니다.

## 화면에서 보이는 것

- **상태 카드 4개**: CPU, 메모리, 디스크, 방화벽. 각 카드는 **정상 / 주의 / 확인 불가** 중 하나입니다.
- **보안 점검 4개**: Windows 보안 실시간 보호, Windows 업데이트 마지막 설치일, 바깥 접속을 기다리는 포트 개수, 시작프로그램 개수.
- 맨 위 한 줄 요약: "점검 8개 중 N개 정상".
- **시간에 따른 변화 그래프**: CPU, 메모리, 디스크 남은 공간 중 선택.
- **최근 기록**: 조회할 때마다 시각과 결과가 남고, 전체/주의/확인 불가/정상으로 걸러 볼 수 있습니다.
- 어두운/밝은 색, 10초마다 자동 조회(켜고 끌 수 있음), 모바일 폭 대응.
- 화면에 항상 **"서버 연결 안 함"** 이 표시됩니다.

## 판정 기준 (학습용 처음 값, `student/judge.mjs`에서 바꿈)

| 항목 | 주의 | 읽지 못하면 |
| --- | --- | --- |
| CPU | 사용률 70% 이상 | 확인 불가 |
| 메모리 | 사용률 80% 이상 | 확인 불가 |
| 디스크 | 남은 공간 15% 이하 | 확인 불가 |
| 방화벽 | 프로필(도메인/개인/공용) 중 하나라도 꺼짐 | 확인 불가 |
| Windows 보안 실시간 보호 | 꺼짐 (다른 백신을 쓰면 정상일 수 있음) | 확인 불가 |
| Windows 업데이트 | 마지막 설치가 60일보다 오래됨 | 확인 불가 |
| 열린 포트 | 바깥 접속 대기 40개 초과 | 확인 불가 |
| 시작프로그램 | 15개 초과 | 확인 불가 |

값을 읽지 못하면 "정상"이라고 말하지 않고 이유와 함께 **확인 불가**로 표시합니다. 기준값은 공식 보안 기준이 아닙니다.

## 수집하는 것 / 수집하지 않는 것

| 수집함 | 수집하지 않음 |
| --- | --- |
| 숫자(사용률, 남은 공간, 개수), 상태, 조회 시각 | PC 이름, 사용자 이름, 프로그램 이름, 파일 이름, 비밀번호, API 키 |

기록은 `student/data/` 폴더에만 저장되고(최근 약 500건) Git에는 올라가지 않습니다. 이 폴더를 지우면 기록이 사라집니다. 공용 PC에서는 `--no-save`를 쓰세요.

## 실제로 구현된 범위와 한계 (솔직하게)

- **읽기 전용**입니다. 막기, 차단, 치료, 설정 변경 기능은 없습니다. 방화벽을 켜고 끄지도 않습니다. 완성된 보안 제품이 아닙니다.
- Windows 전용 항목은 PowerShell 조회 명령(`Get-NetFirewallProfile`, `Get-MpComputerStatus`, `Get-HotFix`, `Get-NetTCPConnection`, `Get-CimInstance`)만 사용합니다. 시험(`test/student.test.mjs`)이 설정을 바꾸는 동사가 없는지 확인합니다.
- **Windows가 아닌 PC**에서는 CPU, 메모리, 디스크만 읽히고 나머지는 "확인 불가"로 나옵니다.
- **관리자 권한이 필요한 항목은 일반 권한에서 "확인 불가"가 될 수 있습니다.** 이때 이유가 화면에 표시됩니다.
- 메모리 사용률은 운영체제가 알려 주는 "남은 메모리"로 계산해서 작업 관리자 값과 조금 다를 수 있습니다.
- 서버는 `127.0.0.1`(내 PC 안)에서만 열리고, 다른 주소로 온 요청은 거절합니다. **외부 서버 연결 기능은 없습니다.**
- 설치 프로그램(`setup.exe`)과 포장(`npm run package-app`)은 만들지 않았습니다. `start.bat`은 설치가 아니라 켜는 단축 파일입니다.
- 열린 포트는 개수만 셉니다. 위험한 포트인지 판단하지 않습니다.

## 확인한 것 / 확인하지 못한 것

- 확인함(개발 환경, Linux): 자동 시험 18건 통과(저장소 전체 281건 통과), 포트 자동 찾기와 `--no-save` 동작, 예제 모드와 화면(데스크톱·모바일·어두운/밝은 색) 브라우저 확인, 브라우저 오류 없음.
- 가짜 PowerShell 결과로: Windows 항목의 해석과 판정, 일부 명령 실패 시 "확인 불가" 처리.
- **확인하지 못함: 실제 Windows PC에서 PowerShell 명령이 내는 진짜 결과.** 개발 환경이 Windows가 아니어서 직접 실행해 보지 못했습니다. `start.bat`과 `start.ps1`도 같은 이유로 Windows에서 실행해 확인하지 못했습니다. 레지스트리 대체 조회와 휴대용 Node 사용 방법도 마찬가지입니다. 첫 실행 때 카드가 "확인 불가"로 나오면 화면의 이유 문구를 보고 알려 주세요.
