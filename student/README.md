# 내 PC 관제 대시보드 (마지막 총공세)

내 **Windows PC**의 상태를 **읽어서 한 화면에 보여 주는** 작은 앱입니다. 완성된 보안 제품이 아니라, 상태를 눈으로 확인하고 기준을 넘으면 알려 주는 점검 화면입니다. 막기·차단·치료·설정 변경은 하지 않습니다.

## 1. 기능 점검표 (핵심 기능 3가지, 지금 되는지 안 되는지)

| 순서 | 핵심 기능 | 지금 | 실제로 되는 것 | 안 되는 것 / 한계 |
| --- | --- | --- | --- | --- |
| 1 | **기록 보기** | **됨** | "다시 조회"를 누를 때마다 시각과 결과(항목 10개)가 `student/data/`에 남고, 최근 기록 목록(전체/주의/확인 불가/정상)과 시간별 그래프로 볼 수 있음 | 최근 약 500건만 보관. Windows 이벤트의 *내용*은 기록하지 않고 건수만 셈 |
| 2 | **내 PC 상태** | **됨** (Windows 실제 확인은 아직) | CPU·메모리·디스크·방화벽 카드 4개와 보안 점검(Windows 보안·업데이트·포트·시작프로그램), 연결과 기록(네트워크·방화벽·Windows 경고·오류·SDP 서버). 카드마다 **측정 시각과 출처** 표시 | Windows가 아닌 PC에서는 CPU·메모리·디스크·네트워크만 읽힘. 개발 환경에서 **진짜 Windows 값은 확인하지 못함** |
| 3 | **위험 알림** | **됨** (앱 화면 안에서만) | 기준을 넘는 항목(주의)이 생기면 화면 위 "위험 알림" 상자, 알림 기록(시작/해소), 브라우저 탭 제목 `(!N)`로 알림. 원하면 "바탕화면 알림 켜기" | **침해(공격)를 판정하지 않음.** 기준값을 넘었다는 알림일 뿐. 앱 창이 열려 있고 조회할 때만 감지(자동 조회를 켜면 10초마다). 이메일·문자·서버 전송 없음. 백그라운드 서비스 아님 |

## 2. 실행 안내 한 장

필요한 것: **Node.js 22 이상 권장**(https://nodejs.org). `npm install`은 필요 없고 관리자 권한도 필요 없습니다. (18.15 이상이면 켜지게 만들었지만 시험은 22에서만 했습니다.)

1. 이 프로젝트 폴더를 엽니다. (ZIP이면 **압축을 푼 폴더**에서)
2. 필요한 설치는 Node.js뿐입니다. `cmd`에서 `node -v`로 확인하세요. 없으면 아래 "Node.js가 없는 PC".
3. `student\start-demo.bat`을 더블클릭하면 예제 화면, `student\start.bat`을 더블클릭하면 실제 PC 상태가 브라우저에 열립니다.

| 하고 싶은 것 | 명령 |
| --- | --- |
| 실제 내 PC 상태 | `node student/server.mjs` 또는 `student\start.bat` |
| 예제 화면 | `node student/server.mjs --demo` 또는 `student\start-demo.bat` |
| PowerShell 도구 | `.\student\start.ps1` / 예제는 `.\student\start.ps1 -Demo` |
| 공용 PC(학원 등): 기록을 파일에 안 남김 | `student\start-shared.bat` 또는 `--no-save` |
| 포트 바꾸기 | `--port=4200` (안 정하면 4173부터 빈 번호를 찾음) |
| 화면 없이 글자로 한 번 조회 | `node student/check-once.mjs` (원인 찾기용, 기록 안 남김) |

**막힌 곳:** Node가 없거나 오래되면 시작 때 안내 문구가 나오고 멈춥니다. `.ps1`이 막히면 `.bat`이나 `node` 명령을 쓰세요(PC 설정은 바꾸지 않아도 됩니다). 4173번 포트가 이미 쓰이고 있으면 자동으로 다음 번호를 씁니다.

예제 화면에는 위쪽에 **"예제 (실제 PC 값이 아니에요)"** 표시가 나옵니다. 화면에는 항상 **"서버 연결 안 함"** 도 표시됩니다.

### Node.js가 없는 PC (학원 컴퓨터 등, 설치 없이)

1. https://nodejs.org/en/download 에서 **Windows Binary (.zip)** 을 받습니다.
2. 압축을 풀고, 안의 파일들을 `student\node` 폴더에 옮깁니다. (`student\node\node.exe`가 있어야 합니다.)
3. `student\start.bat`을 더블클릭합니다. `start.bat`이 `student\node\node.exe`를 먼저 찾아 씁니다. PC에 설치하거나 설정을 바꾸는 것은 없습니다. `student\node`는 Git에 올라가지 않습니다.

### 여러 Windows PC에서 쓸 때 (대비한 것)

- **PowerShell이 막힌 PC**: 명령을 인코딩해서 `-NoProfile`로 실행하고 실행 정책 설정은 바꾸지 않습니다. 실행이 안 되면 그 항목만 이유와 함께 "확인 불가"가 됩니다.
- **방화벽 조회가 막힌 PC**: 레지스트리의 방화벽 설정값을 *읽기만* 하는 방법으로 한 번 더 시도합니다(그룹 정책이 따로 있으면 실제와 다를 수 있음). **네트워크 조회가 막히면** Node 기본 기능으로 "연결됨/안 됨"만 대신 읽습니다.
- **폴더에 쓸 수 없는 PC**: 임시 폴더에 기록하고, 그것도 안 되면 메모리에만 기록합니다(화면 위에 저장 방식 표시).
- **공용 PC**: `--no-save`는 기록을 파일에 남기지 않습니다.

## 3. 화면 구성

- **맨 위 요약**: "점검 10개 중 N개 정상", 조회 시각, 10초 자동 조회, "다시 조회"(읽는 동안 "새로 읽는 중…").
- **위험 알림**: 지금 주의인 항목, 시작 시각, 알림 기록. "침해 판정이 아니에요" 문구 포함.
- **읽지 못한 항목 상자**: 확인 불가 항목, 이유, 다음 행동. (예: "디스크 값을 읽지 못했습니다. 이유: … 권한을 확인한 뒤 '다시 조회'를 눌러 주세요.")
- **상태 카드 4개**: CPU, 메모리, 디스크, 방화벽. 각각 **정상 / 주의 / 확인 불가**. 권한 때문이면 "확인 불가 · 권한 없음".
- **보안 점검 4개**: Windows 보안 실시간 보호, Windows 업데이트(마지막 설치일), 열린 포트(개수), 시작프로그램(개수).
- **연결과 기록**: 네트워크 연결(유선/무선), 방화벽(읽기만 함), Windows 경고·오류 건수(침해 판정 아님), **SDP 서버(기본: SDP 미연결 · 서버 연결 안 함)**. PC 조회 결과와 서버 연결 상태를 따로 보여 줍니다.
- **시간에 따른 변화 그래프**, **최근 기록**(전체/주의/확인 불가/정상), 모바일 폭 대응, "화면 읽는 법".
- **기록 내보내기(CSV)**: 조회 기록을 엑셀에서 열 수 있는 CSV로 내려받습니다(숫자·상태·시각만). 시연의 "근거"로 쓸 수 있습니다.
- **기록 지우기**: 확인 창을 거친 뒤 이 앱의 조회 기록을 모두 지웁니다(되돌릴 수 없음). 공용 PC에서 쓰고 나서 지우는 용도입니다.
- **화면 색**: 항상 **어두운 화면이 기본**입니다(윈도우 밝은 모드를 따라가지 않음). "색" 버튼을 누르면 밝은 화면으로 바꿀 수 있고, 고른 색은 이 브라우저에 기억됩니다.
- 카드와 줄마다 **"몇 시에 측정 · 어디서 읽었는지"** 가 적혀 있습니다.

## 4. 판정 기준 (학습용 처음 값, `student/judge.mjs`에서 바꿈)

| 항목 | 주의 | 읽지 못하면 |
| --- | --- | --- |
| CPU | 사용률 70% 이상 | 확인 불가 |
| 메모리 | 사용률 80% 이상 | 확인 불가 |
| 디스크 | 남은 공간 15% 이하 | 확인 불가 |
| 방화벽 | 도메인·개인·공용 중 하나라도 꺼짐 | 확인 불가 |
| Windows 보안 실시간 보호 | 꺼짐 (다른 백신을 쓰면 정상일 수 있음) | 확인 불가 |
| Windows 업데이트 | 마지막 설치가 60일보다 오래됨 | 확인 불가 |
| 열린 포트 | 바깥 접속 대기 40개 초과 (개수만 셈, 위험 판단 아님) | 확인 불가 |
| 시작프로그램 | 15개 초과 | 확인 불가 |
| 네트워크 연결 | 연결 안 됨 | 확인 불가 |
| Windows 경고·오류 | 최근 24시간 100건 초과 (침해 판정 아님, 최대 500건까지 셈) | 확인 불가 |

값을 읽지 못하면 "정상"이라고 말하지 않고 이유와 함께 **확인 불가**로 표시합니다. 기준값은 공식 보안 기준이 아닙니다.

## 6. 실제로 구현된 범위와 한계 (솔직하게)

- **읽기 전용**입니다. 막기·차단·치료·설정 변경 기능은 없고, 방화벽을 켜고 끄지도 않습니다. 완성된 보안 제품이 아닙니다.
- Windows 항목은 PowerShell 조회 명령(`Get-NetFirewallProfile`, `Get-MpComputerStatus`, `Get-HotFix`, `Get-NetTCPConnection`, `Get-CimInstance`, `Get-NetAdapter`, `Get-WinEvent`)만 씁니다. 시험이 설정을 바꾸는 동사가 없는지, 큰따옴표가 없는지 확인합니다.
- **Windows가 아닌 PC**에서는 CPU·메모리·디스크·네트워크만 읽히고 나머지는 "확인 불가"입니다.
- 관리자 권한이 필요한 항목은 일반 권한에서 "확인 불가 · 권한 없음"이 될 수 있습니다. 앱이 스스로 권한을 올리지는 않습니다.
- 메모리 사용률은 운영체제가 알려 주는 "남은 메모리"로 계산해서 작업 관리자 값과 다를 수 있습니다(차이 크기는 Windows에서 확인하지 못함).
- 서버는 `127.0.0.1`(내 PC 안)에서만 열리고, 다른 주소로 온 요청은 거절합니다. **외부 서버 연결 기능은 없습니다.** "SDP 서버"는 항상 "SDP 미연결"로 표시되는 안내 줄입니다.
- 위험 알림은 앱 화면 안(와 선택한 바탕화면 알림)에서만 동작하며, 앱이 꺼져 있을 때는 감지하지 못합니다.
- 설치 프로그램(`setup.exe`)과 포장(`npm run package-app`)은 만들지 않았습니다. `start.bat`은 설치가 아니라 켜는 단축 파일입니다.

## 7. 시연 순서 · 한계 · 근거

**시연 순서** (처음부터 끝까지)

1. **기록 보기**: `start-demo.bat`(예제)을 켜고 "다시 조회"를 몇 번 누른다 → 최근 기록과 그래프가 쌓이고, 목록을 "주의"로 걸러 본다.
2. **내 PC 상태**: `start.bat`(실제)을 켠다 → 카드 4개, 보안 점검, 연결과 기록을 보고 "확인 불가"가 있으면 이유를 읽는다.
3. **위험 알림**: 주의가 있는 항목이 "위험 알림" 상자와 알림 기록에 뜨는지, 탭 제목에 `(!N)`이 붙는지 본다.

**한계**

- 개발 환경(Linux)에서는 Windows 전용 항목을 읽지 못해 "확인 불가"로 나온다. 진짜 Windows 값은 Windows PC에서 실행해 봐야 확인된다.
- 일부 이벤트 기록·보안 상태는 권한이나 PC 정책에 따라 읽히지 않을 수 있다. 그때는 숨기지 않고 "확인 불가"로 표시한다.
- 주의 기준값은 학습용이며 공식 기준이 아니다. 위험 알림은 침해 판정이 아니다.

**근거**

- 화면 캡처: 저장소의 `docs/` 폴더(포트폴리오 저장소) 스크린샷은 *예제 모드*의 가짜 값이다.
- 실행 기록: `node --test test/student.test.mjs` 출력(아래 "확인한 것"), `node student/check-once.mjs` 출력.
- 커밋 번호: 제출하는 40자리 커밋 번호(`git rev-parse HEAD`).

## 8. 확인한 것 / 확인하지 못한 것

- **확인함 (개발 환경, Linux):** student 자동 시험 27건 통과, 저장소 전체 시험 290건 통과, 예제 모드·실제 모드 화면(데스크톱·모바일·어두운/밝은 색)을 브라우저에서 열어 클릭 동작과 오류 없음 확인, 포트 자동 찾기, `--no-save`, 다른 주소 요청 거절.
- **가짜 PowerShell 결과로:** Windows 항목의 해석과 판정, 일부 명령 실패 시 "확인 불가"와 대체 방법(방화벽 레지스트리, 네트워크 Node 기본) 동작.
- **확인하지 못함:** 실제 Windows PC에서 PowerShell 명령이 내는 진짜 결과, `start.bat`·`start.ps1`·휴대용 Node 방식을 Windows에서 실행, **다른 사람이 내 도움 없이 이 안내만 보고 따라 해 보기**.
