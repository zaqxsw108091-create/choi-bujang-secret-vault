# 12단계 재제출용 기록 (2026-10-16)

첫 심판 결과(45/100, `S12_SCREEN_MISMATCH`)의 원인은 작전실 화면이 아니라 제출 묶음 생성이었습니다. `main`의 마지막 커밋이 PR 병합 커밋이라 `scripts/bundle.mjs`가 바뀐 파일을 찾지 못했습니다.

이 파일은 병합 커밋 없이 `main`에 직접 올린 일반 커밋(부모 1개)의 변경입니다. 코드와 설정은 바꾸지 않았습니다. 12단계의 실제 기능과 배포 실측 결과, 미실행 항목(41종 시험 등)은 `README.md`의 12단계 절을 보세요.

확인 방법: `git fetch origin && git log -1 --format="%h %p" origin/main`에서 해시가 하나만 나오면 일반 커밋입니다.

두 번째 판정(0점, 최고 45점 유지)은 심판의 격리된 제출 환경에서 `npm run bundle`이 GET·HEAD 이외의 요청을 보내 끝까지 실행되지 못한 것이 원인이었습니다. `src/attack-check.mjs`에서 쓰기 요청을 모두 없애고 해당 점검 9개를 `미실행`으로 기록하도록 고쳤으며(PR #63), 쓰기 점검의 배포 실측 결과는 `README.md`의 "12단계 두 번째 심판 결과와 고침" 절에 있습니다. PR #63도 병합 커밋으로 합쳐져서, 이 파일의 변경을 일반 커밋으로 `main`에 올렸습니다.
